# 🎬 📚 life-log | インプット＆日々の感想

日々の読書、映画、ドラマの鑑賞ログ、日々の感想を蓄積していくパーソナルリポジトリです。  
以前まではnotionで管理してたのですが、人に見られても困らないことに気づいたのでこちらに移行しました。  
基本的に全てのコンテンツで**ネタバレを含みます**。  
エンジニアとしての技術力だけでなく、**「日常のあらゆる作品から気付きを得るアンテナ」** と **「自分の言葉でアウトプットする言語化力」** を磨くために運用しています。

---

## 🎨 記録のジャンル

以下の4つのカテゴリーに分けて、それぞれの作品から得たインプットをMarkdown形式でまとめています。

### 🖋️ 1. ミニブログ (`/blog`)
日々の学習による技術的な気づき（Git、SQL、Blender等）や、自己管理（メンタルコントロール・体調の波との付き合い方）に焦点を当てた自己内省の記録です。  
障害特性と向き合いながら、どのように日々の学習を継続し、リカバリーを図っているかのプロセスも開示しています。  

### 📚 2. 読書ログ (`/books`)
年々本を読むのが苦手になっています。感想文です。

### 📺 3. ドラマログ (`/dramas`)
国内外のドラマの鑑賞記録です。映画とは違う構成の面白さ、映像美などの感想文です。

### 🎬 4. 映画ログ (`/movies`)
作品のストーリー構成、映像美、心に刺さったセリフなどを記録しています。  
基本的にすべてが感想文です。
