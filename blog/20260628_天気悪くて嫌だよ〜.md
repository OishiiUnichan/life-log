## 気づき

`@param`（パラム）は、**「メソッドが受け取る引数（データ）の説明メモ」**。  
Javaのドキュメント機能（Javadoc）のルール。

### 📌 メリット
これを書いておくと、**VS Codeでコードを書くときにポップアップで説明が表示される**ようになり、使い方が一目でわかるようになる。

### ✍️ 書き方
```java
/**
 * @param score テストの点数（0〜100）
 */
public void checkScore(int score) { ... }

```

* **構文**: `@param [引数の変数名] [説明文]`
* **語源**: 引数を意味する「**parameter**（パラメーター）」の略。
