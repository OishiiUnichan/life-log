### 授業中の気づき

#### `const` と `let` の違い

| | `let` | `const` |
|:--|:--|:--|
| 再代入（箱の替え） | ✅ できる | ❌ できない |
| 中身の変更 | ✅ できる | ✅ できる |

## ポイント

`const` は**変数名（箱）を固定**するだけで、中身は変更できる。

```js
const array = [1, 2, 3];
array = [4, 5, 6];   // ❌ Assignment to constant variable.
array[0] = 99;       // ✅ [99, 2, 3]
```

> ※ `Date` オブジェクト・配列など、どのオブジェクトでも同じ。
